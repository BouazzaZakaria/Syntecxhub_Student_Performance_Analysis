# Student Performance Analysis

This project uses a Power BI report and student dataset to explore academic results, compare available student groups, and identify practical ways to improve performance.

## Project Activities

- Load and preprocess the student dataset, including subject marks and other available student measures.
- Analyze subject-wise and overall performance trends.
- Examine factors associated with results, including study hours and attendance where those fields are available in the report's data model.
- Compare performance across the groups and classes available in the source data.
- Present findings with bar, pie, and line charts.
- Summarize insights that can guide improvements in academic results.

## Files

- `Student Performance Analysis.pbix` - Power BI report containing the analysis and visualizations.
- `Students_Dataset.xlsx` - Spreadsheet used as a student dataset.

## Dataset Notes

The included spreadsheet has columns for Student ID, gender, ethnicity, parental education, test preparation, and math, reading, and writing scores. It does not contain attendance, study-hours, or class columns; those analyses require the relevant fields to be available from another source or in the report's data model. Interpret observed relationships as associations, not proof of cause and effect.
